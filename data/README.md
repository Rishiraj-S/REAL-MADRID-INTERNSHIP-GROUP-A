# data/

| Directory | Purpose |
|---|---|
| `raw/` | Immutable source data — kept local, out of git |
| `external/` | Third-party data — kept local, out of git |
| `interim/` | Intermediate generated data |
| `processed/` | Production artifacts consumed by the app and training pipeline |

## Key files

| File | Description |
|---|---|
| `data_acute_vs_chronic.zip` | Bootstrap archive (committed). Extracted automatically by `train_models.py` |
| `raw/data_acute_vs_chronic.csv` | Extracted raw CSV — one row per training period (gitignored) |
| `processed/daily.parquet` | Player-day grid with all three load metrics + session flags. Generated by `train_models.py`. Used by both the training pipeline and the Streamlit app at runtime |

## Generating processed data

```bash
python train_models.py
```

This extracts the CSV from the ZIP if needed, runs the full cleaning and aggregation pipeline, and writes `data/processed/daily.parquet`.
